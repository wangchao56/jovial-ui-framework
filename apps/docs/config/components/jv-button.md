# JvButton 按钮

## 基础用法

```vue
<JvButton type="primary">
主要按钮
</JvButton>
```

## Props

| 参数 | 说明     | 类型                                      | 默认值    |
| ---- | -------- | ----------------------------------------- | --------- |
| type | 按钮类型 | 'primary'｜'success'｜'warning'｜'danger' | 'primary' |
| size | 按钮尺寸 | 'small'｜'medium'｜'large'                | 'medium'  |

## 事件

| 事件名 | 说明     | 参数              |
| ------ | -------- | ----------------- |
| click  | 点击事件 | event: MouseEvent |
