
# 排版

## 需求分析
尽可能的满足 WCAG AA 标准，以及尽可能的满足用户的需求
使用原生HTML标签，尽可能的减少自定义标签 并且符合无障碍标准


- 标题
  对于标题，需要支持不同的级别，以及不同的样式 使用h1-h6标签
- 段落
  对于段落，需要支持缩进、对齐、标点压缩、避头尾
  使用p标签
- 列表 
  对于列表，需要支持不同的样式，以及不同的级别
  使用ul、ol标签
- 引用 
  对于引用，需要支持不同的样式，以及不同的级别
  使用blockquote标签
- 代码 
  对于代码，需要支持不同的样式，以及不同的级别
  使用code标签
- 普通文本
  使用span标签 根据不同需求，使用不同的HTML标签 比如 链接（a）、强调（em）、删除（del）、插入（ins）、代码（code）、引用（cite） 加粗(strong) 斜体(i) 下划线(u) 
  
  对于普通文本，需要支持不同的样式，以及不同的级别 
`
<a>、<em>、<strong>、<small>、<cite>、<q>、<dfn>、<abbr>、<time>、<code>、<var>、<samp>、<kbd>、<sub>、<sup>、<i>、<mark>、<ruby>、<rp>、<rt>、<bdo>、<span>、<br>、<wbr>。
`
