## 测试技术说明

在测试中，我们使用了以下技术和方法：

- 使用 `mount` 函数创建组件实例
- 使用 `find` 和 `findComponent` 方法查找DOM元素和子组件
- 使用 `classes`、`attributes` 和 `text` 方法检查元素属性
- 使用 `trigger` 方法模拟用户交互
- 使用 `emitted` 方法检查事件触发情况

## 组件功能概述

JvAvatar组件支持以下主要功能：

1. **多种显示模式**：

   - 图片模式（通过src属性）
   - 文本模式（通过text属性，显示文本首字母）
   - 图标模式（通过icon属性或icon插槽）
   - 自定义内容（通过默认插槽）

2. **样式自定义**：

   - 多种预设尺寸（tiny, small, medium, large, x-large）
   - 自定义尺寸（通过customSize属性）
   - 形状选择（circle, square）
   - 边框显示（bordered属性）
   - 自定义背景色和文本颜色

3. **交互功能**：
   - 可点击（clickable属性）
   - 点击事件（click事件）
   - 图片加载错误处理（error事件）
