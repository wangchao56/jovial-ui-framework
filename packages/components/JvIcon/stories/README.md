## 测试技术说明

在测试中，我们使用了以下技术和方法：

- 使用 `mount` 函数创建组件实例
- 使用 `find` 和 `findComponent` 方法查找DOM元素和子组件
- 使用 `classes`、`attributes` 和 `text` 方法检查元素属性
- 使用 `props` 方法检查组件属性
- 使用 `html` 方法检查渲染的HTML内容

## 组件功能概述

JvIcon组件支持以下主要功能：

1. **多种图标来源**：

   - Iconify图标库（通过name属性）
   - 内部图标（通过$开头的name属性）
   - 自定义内容（通过默认插槽）

2. **尺寸设置**：

   - 预设尺寸（tiny, small, medium, large, x-large）
   - 自定义数字尺寸（通过size属性）

3. **样式自定义**：

   - 图标颜色（color属性）
   - 图标类型（type属性）
   - 自定义类名（class属性）

4. **内部图标集**：
   - 提供了丰富的内部图标，如$loading、$close、$eye等
   - 内部图标以$开头，方便识别和使用
